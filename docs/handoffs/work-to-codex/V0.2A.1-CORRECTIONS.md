### R1 — P2: classifier execution is inferred from usable shot resolution

Location: `app/backend/qc/analysis.py`, `photo_checks`, reviewed lines 151–169; prediction is actually attempted in `analyze_shoot` before this function is called.

With an active classifier returning `rear` at confidence `0.79`, the model executes successfully, but the persisted `shot_classification` check reports `execution=not_run`. Resolution remains unknown because confidence is below the existing 0.8 threshold. That threshold affects whether the result can resolve the shot, not whether inference executed. A.1 explicitly separates execution from outcome; an inconclusive check must not be represented as a check that never ran.

Independent fixture result:

```text
model_calls: 1
prediction: rear
confidence: 0.79
execution: not_run
outcome: unknown
reason: unresolved_shot
```

The same conditional also reports `completed/pass` when a human-verified shot resolves without any active classifier. Preserve valid human operational resolution, but do not let it imply model inference occurred. Treat both cases as one correction to execution/provenance semantics.

### Reproduce R1

Run from repository root with locked dependencies installed:

```python
# PYTHONPATH=app/backend:tests .venv/bin/python <this_script.py>
from tempfile import TemporaryDirectory
from unittest.mock import patch
from fastapi.testclient import TestClient
from qc.main import create_app
from qc.db import ModelVersion
from test_revisions import batch, detail
from test_workflows import analyze

with TemporaryDirectory() as directory:
    app = create_app(directory, start_worker=False)
    with TestClient(app) as client:
        shoot_id = batch(client, 1, shot_types=['rear'])
        with app.state.factory() as session:
            session.add(ModelVersion(name='stub', artifact_key='models/stub.pt',
                                     classes=['rear'], status='active'))
            session.commit()
        (app.state.data / 'models/stub.pt').write_bytes(b'stub')
        with patch('qc.classifier.predict', return_value=('rear', 0.79)) as predict:
            analyze(app, shoot_id)
            result = detail(client, shoot_id)
            check = next(item for item in result['qc_evidence']['checks']
                         if item['check_id'] == 'shot_classification')
            print(predict.call_count, check)
            assert predict.call_count == 1
            assert check['execution'] == 'completed'  # Fails on reviewed head.
```
