# v0.2 Human Training Mode / guided capture

**Status:** approved for v0.2  
**Difficulty:** 3/5 for the practical version  
**Value:** 5/5

## Goal

Allow a trainee to learn a generic or dealership-specific vehicle photo sequence independently while still receiving visual guidance, automated Vehicle QC analysis, manager review, and progress tracking.

## Main workflow

1. Trainee opens Human Training Mode.
2. Select:
   - generic training sequence, or
   - specific dealership sequence.
3. Select vehicle body type:
   - 4-door truck,
   - 2-door truck,
   - SUV,
   - 4-door car,
   - 2-door car.
4. Show the full sequence in a three-wide preview grid.
5. Start training.
6. Show the first reference image full-screen.
7. Show optional manager-created instructions/annotations.
8. Trainee taps the screen.
9. Reference fades into an adjustable-opacity ghost overlay over the live camera.
10. Trainee aligns the real vehicle and captures.
11. Advance to next shot.
12. Repeat through sequence.
13. Submit completed training set to normal Vehicle QC analysis.
14. Show trainee results.
15. Add the attempt to a manager Training Review queue.
16. Manager can review, annotate, coach, and approve/readiness-mark.

## Reference / camera behavior

The practical v0.2 implementation should remain browser-based.

Use live camera access through the mobile browser with:

- rear-facing camera preference,
- clear camera permission state,
- semi-transparent reference image,
- separately controllable annotation layer,
- easy opacity adjustment,
- mobile-first controls.

The trainee must always be able to see enough of the live camera to adjust position.

## Reference assets

A manager can select a high-quality existing Vehicle QC shoot and choose:

**Add to Human Training Library**

Then:

- assign body type,
- assign generic/dealership sequence,
- select which photos are reference shots,
- replace individual references later without rebuilding the whole sequence.

## Annotation model

Do not burn annotations permanently into the JPEG.

Store annotations separately.

Initial tools:

- freehand drawing,
- arrow/line,
- rectangle/polygon/outline,
- translucent highlight,
- short text.

Each annotation should keep:

- coordinates normalized to image dimensions,
- type,
- style/opacity,
- text if present,
- author,
- revision/timestamp.

Trainees may optionally hide annotations while keeping the reference overlay.

## Instruction fields per shot

Allow short structured coaching:

- shot name,
- where to stand,
- approximate camera height,
- framing landmark,
- common mistake,
- optional manager note.

## Training levels

### Guided
- strong reference overlay,
- annotations,
- instructions.

### Assisted
- lighter reference overlay,
- fewer instructions.

### Test
- shot name/sequence only,
- no ghost reference during capture,
- QC after completion.

This creates a progression from imitation to independent competency.

## Results

After a sequence:

- overall score,
- pass/fail count,
- shot-by-shot QC,
- missing shots,
- repeated/duplicate shots,
- reference vs trainee comparison,
- manager comments.

Provide a swipe/fade comparison between the reference and trainee photo.

## Repeat failed shots

Allow:

**Practice weak shots**

Create a mini-sequence only from failed/weak shots.

Do not require repeating the entire vehicle when only a few shots need work.

## Trainee history

Track:

- attempts,
- date,
- sequence/dealership,
- body type,
- score,
- first-pass rate,
- weak shot types,
- manager notes,
- Guided/Assisted/Test level,
- readiness/qualification state.

## Dealership readiness

Managers should be able to see a matrix such as:

- General exterior — Qualified
- Dealer A — Qualified
- Dealer B — Training
- Dealer C — Not started

Qualification rules may initially be manual or simple threshold-based.

Do not over-automate certification until real usage establishes useful thresholds.

## Spoken prompts

Approved for v0.2 if low-risk:

- speak shot name,
- optionally speak manager instruction,
- allow mute.

This lets the trainee keep eyes on the vehicle.

## Automatic body-style suggestion

Stretch feature for v0.2 only if existing model/data make it reliable cheaply.

Manual category selection remains authoritative.

## Manager training review

Create a distinct training review list.

Managers need:

- trainee,
- dealership/sequence,
- body type,
- attempt score,
- failed/weak shots,
- comparison tools,
- coaching notes,
- approval/readiness status.

## Later features — not required for v0.2

- real-time computer-vision "move left/right/closer/farther,"
- automatic framing score before capture,
- auto-shutter,
- sensor-assisted camera position,
- robust offline capture/sync,
- native mobile camera controls,
- advanced AR.

These are feasible later but should not delay the practical training workflow.

## Why this belongs in Vehicle QC

This feature reuses:

- dealership sequences,
- shot taxonomy,
- training/reference photos,
- users,
- QC models,
- manager review,
- employee performance history.

It is therefore a coherent extension rather than unrelated product bloat.
