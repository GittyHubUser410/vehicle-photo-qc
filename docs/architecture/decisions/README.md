# Architecture Decision Records

This folder stores durable architecture decisions for Vehicle QC.

Create an ADR when a decision is likely to matter to future developers/agents or constrains future implementation. Do not use ADRs for trivial code-level choices.

## Format

- Title
- Status
- Context
- Decision
- Alternatives Considered
- Consequences
- Supersedes / Superseded By (when applicable)

Accepted ADRs are historical records. If an architectural decision changes materially, create a new ADR that supersedes the previous record rather than silently rewriting the old decision.
